# 🏥 Clínica Inteligente

Este projeto é um **sistema de autenticação e painel de gerenciamento** para clínicas médicas.

## 📌 Objetivo do Projeto

O objetivo foi criar uma interface limpa e responsiva para:
- Gerenciamento de usuários e pacientes
- Autenticação de login (com JWT)
- Acesso seguro a áreas administrativas

- ## 🛠 Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, Vue.js (ou React se preferir)
- **Estilo:** CSS puro com efeitos de hover, sombras e layout responsivo
- **Backend:** Node.js + Express
- **Banco de Dados:** MongoDB (ou SQLite para versão simples)
- **Autenticação:** JWT (JSON Web Token)

- ## ⚙️ Como Rodar o Projeto

- ## 1️⃣ Pré-requisitos
Certifique-se de ter instalado:
- [Node.js](https://nodejs.org) (v16+)
- [npm](https://www.npmjs.com/)

- ## 2️⃣ Instalar Dependências
Backend
- cd backend
- npm install
- npm run dev
  
Frontend
- cd frontend
- npm install
- npm run dev

- ## 3️⃣ Abra no navegador
- http://localhost:5173
